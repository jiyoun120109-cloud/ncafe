# ncafe 프로젝트 기능 정리 (채널 공유용)

아래 형식으로 각 조 채널에 보내면 됩니다. (기간: ~ 본인 발표 전까지)

---

### 👤 사용자 (고객)

| 기능 | 설명 |
|------|------|
| 🏠 **홈페이지** | 히어로 섹션, 인기/추천 메뉴, 위치 안내 |
| 📋 **메뉴 조회** | 카테고리별 필터링, 정렬, 판매 상태 필터, 메뉴 상세 (이미지·옵션·영양정보) |
| 🛒 **장바구니** | 메뉴 담기, 수량·옵션 선택, 비회원/회원 장바구니 병합 |
| 💳 **주문/결제** | 매장/포장 선택, 쿠폰 적용, 토스페이먼츠 결제 (카드 등) |
| 🎫 **스탬프/쿠폰** | 주문 시 스탬프 적립, 10개 적립 시 무료 음료 쿠폰 자동 발급, 쿠폰 사용 |
| ❤️ **즐겨찾기** | 메뉴 즐겨찾기 등록/해제 |
| 👤 **마이페이지** | 주문 내역·취소, 즐겨찾기, 쿠폰 관리, 스탬프, 프로필 수정·비밀번호 변경, 알림 |
| 🔐 **인증** | 일반 로그인/회원가입 |
| 🤖 **AI 챗봇** | Gemini 기반 게스트 채팅, 스트리밍 응답, 메뉴 추천·장바구니 담기 도구 연동 |
| 📝 **1:1 문의** | 문의 등록 및 관리자 답변 확인 |
| 📢 **공지사항** | 공지 목록·상세 (중요 공지 상단 고정) |

---

### 🔧 관리자

**계정:** `admin` / `admin123` (data.sql 시드 기준)

| 기능 | 설명 |
|------|------|
| 📊 **대시보드** | 오늘 매출, 기간별 매출 통계(일/주/월), 차트 시각화, 결제 대기·완료 주문 목록 |
| 📋 **메뉴 관리** | CRUD, 다건 이미지 업로드(대표/서브), 이미지 순서·대표 설정, 옵션 설정, 카테고리 탭·드롭다운 필터/정렬 |
| 📂 **카테고리 관리** | 메뉴 관리 화면 내 카테고리 탭에서 추가/수정/삭제·순서 변경, 아이콘 업로드 |
| 📦 **주문 관리** | 주문 목록, 상세, 상태 변경, 주문 취소(쿠폰 반환·스탬프 롤백) |
| 👥 **회원 관리** | 회원 목록·상세, 역할 관리, 비밀번호 초기화(앱 알림 + 선택 시 이메일 발송) |
| 📢 **공지사항** | 공지 등록/수정/삭제, 에디터·파일 첨부 |
| 💬 **문의 관리** | 고객 문의 조회, 답변 작성 |
| ⚙️ **설정** | 카페명·주소·영업 관련 설정 등 |
| 🧠 **RAG 관리** | AI 챗봇용 PDF 문서 업로드, 벡터 DB 관리 |
