# 처방약 배달 앱
## 비대면 진료 이후, “찾으러 가기 어려운” 사람을 위한 해결책

프로젝트 아이디어 발표

---

## 1. 배경: 비대면 진료와 처방전

- **비대면(원격) 진료**가 일상이 됨
  - 코로나 이후 비대면 진료·처방이 정착
  - 병원 방문 없이 진료 → **처방전 발급** → **원하는 약국 선택** → **약국 방문 수령**

- 그런데 **“약국에 가지 못하는 사람”**은?
  - 혼자 사는 노인, 장기 요양·재택 환자
  - 육아·근무로 외출이 어려운 경우
  - 거동이 불편한 경우, 대리 수령이 어려운 경우

→ **“처방은 받았는데, 약을 받으러 가지 못한다”**는 공백이 생김

---

## 2. 문제 정의

| 구분 | 내용 |
|------|------|
| **상황** | 비대면 진료 후 처방전이 특정 약국으로 전달됨 |
| **일반 흐름** | 환자가 그 약국에 직접 가서 약을 수령 |
| **문제** | **직접 방문이 어려운 사람**은 처방을 받아도 약을 받기 힘듦 |
| **결과** | 처방을 포기하거나, 무리해서 나가거나, 대리를 구해야 함 |

**“처방의 마지막 한 걸음”을 도와주는 서비스가 있으면 좋겠다**

---

## 3. 아이디어: 처방약 배달 앱

**진료 → 처방전 전달 → (선택) 약국 방문 수령**  
**또는**  
**진료 → 처방전 전달 → 앱에서 “배달 신청” → 약을 집으로 배달**

- 환자가 **원하는 약국**을 선택한 뒤,  
  **“방문 수령”** / **“배달 신청”** 중 선택
- 배달 신청 시: 약국이 조제 완료 후 **배달 파트너(앱)**가 픽업 → **환자 주소로 배달**
- 결제·수령 확인은 앱에서 처리 (현금/카드, 서명·OTP 등)

---

## 4. 기대 효과

- **환자**
  - 외출이 어려워도 처방받은 약을 안전하게 수령
  - 혼자 사는 가구, 재택 요양자, 바쁜 직장인 등에게 실질적 도움

- **약국**
  - “찾으러 오기 어려운” 고객까지 서비스 가능
  - 배달 수수료·플랫폼 이용으로 매출 다각화

- **사회**
  - 처방 이행률 향상 → 건강 관리 개선
  - 비대면 진료의 완결성 강화

---

## 5. 핵심 기능 (예시)

1. **처방·약국 연동**
   - 비대면 진료 플랫폼/병원·약국과 처방전·조제 정보 연동 (API 또는 수동 입력)

2. **배달 신청**
   - “방문 수령” / “배달” 선택, 주소·희망 시간대 입력, 배달비 결제

3. **약국·배달원 앱**
   - 약국: 조제 완료 후 “배달 픽업 요청”
   - 배달원: 픽업 → 배달 → 수령 확인

4. **안전·규정 대응**
   - 본인 확인, 수령자 확인(서명/OTP), 약 포장·운송 기준 준수

## 6. 고려할 점

| 영역 | 내용 |
|------|------|
| **규제** | 의약품 배달 허용 범위, 약사법·전자처방 등 법적 검토 필요 |
| **협력** | 병원·비대면 진료 플랫폼, 약국, 배달 파트너와의 협력 구조 |
| **비용** | 배달비·플랫폼 수수료, 초기 구축·운영 비용 |
| **보안·프라이버시** | 처방정보·건강정보 보호, 개인정보 처리 |

→ **아이디어 검증 단계**에서는 “처방약 배달 수요·시장성”에 초점을 두고, 규제·사업화는 이후 단계에서 구체화하는 방식도 가능

---

## 7. 정리

- **문제**: 비대면 진료 후 “약국에 찾으러 가기 어려운” 사람이 많아짐
- **아이디어**: 처방전을 받은 뒤 **“배달”**을 선택하면, **약을 집까지 배달**해 주는 앱
- **타깃**: 혼자 사는 사람, 외출이 어려운 사람, 거동이 불편한 사람 등
- **다음 단계**: 수요 조사, 규제·사업 모델 조사, MVP(최소 기능) 설계
