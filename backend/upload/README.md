# 메뉴 이미지 업로드 폴더

이 폴더의 파일은 백엔드 정적 리소스로 제공됩니다.  
Docker 실행 시 이 경로가 컨테이너의 `/app/upload`에 마운트됩니다.

## 이미지가 안 나올 때

- `data.sql`에 등록된 메뉴 이미지 파일명(예: `americano.png`, `cafelatte.png`)과 **같은 이름**의 파일을 이 폴더에 넣어 주세요.
- Docker 사용 시: 호스트의 `backend/upload/`에 파일을 두면 컨테이너에서 그대로 노출됩니다.
- 파일을 추가·변경한 뒤에는 백엔드(또는 Docker 컨테이너)를 재시작할 필요는 없습니다.
