# 메뉴 이미지 업로드 폴더

이 폴더의 파일은 백엔드 정적 리소스로 제공됩니다.

## 배포(Docker) 환경

- **GitHub Actions 배포 시**: 이 폴더(`backend/upload/`)에 있는 이미지가 자동으로 호스트 `/home/yun/upload`로 복사됩니다. (이미 있는 파일은 덮어쓰지 않음)
- 호스트 `/home/yun/upload`는 docker-compose에서 백엔드 컨테이너의 `/app/upload`로 마운트되므로, 여기 넣은 시드 이미지가 배포 후 메뉴 이미지로 노출됩니다.

## 이미지가 안 나올 때

- `data.sql`에 등록된 메뉴 이미지 파일명(예: `americano.png`, `cafelatte.png`)과 **같은 이름**의 파일을 이 폴더에 넣고 커밋·푸시하면, 다음 배포 시 자동으로 복사됩니다.
- 로컬 Docker 사용 시: 호스트의 `backend/upload/`(또는 마운트된 경로)에 파일을 두면 컨테이너에서 그대로 노출됩니다.
- 파일을 추가·변경한 뒤에는 백엔드(또는 Docker 컨테이너)를 재시작할 필요는 없습니다.
